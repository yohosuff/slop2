# Navmesh Demo - Earcut Triangulation

An interactive demonstration of randomized 2D level geometry with navmesh triangulation using the Earcut library.

## Features

- **Randomized Level Generation**: Creates polygonal level geometry with 5-12 vertices
- **Earcut Triangulation**: Uses the earcut library to triangulate the level polygon into a navmesh
- **Clear Visualization**: 
  - Green outline and vertices show the level geometry
  - Colorful triangles show the navmesh generated by earcut
  - Each triangle has a different color for clear differentiation
- **Interactive**: Tap/click to generate a new random level
- **Mobile-First**: Touch support, responsive design, PWA-ready

## Usage

Simply open `index.html` in a web browser. The demo will:
1. Generate a random polygon representing level geometry
2. Triangulate it using earcut to create a navmesh
3. Display both the level geometry (green) and navmesh triangles (colored)

Tap or click anywhere to generate a new random level.

## Technical Details

- Pure HTML5, Vanilla JavaScript (ES6+), and CSS3
- No build tools or frameworks required
- Uses earcut v2.2.4 for fast polygon triangulation
- Mobile-optimized with touch event support
- 60 FPS rendering using requestAnimationFrame

## Files

- `index.html` - Main HTML file
- `css/style.css` - Responsive styles
- `js/earcut.js` - Earcut triangulation library
- `js/game.js` - Main demo logic
- `manifest.json` - PWA manifest
