# Simple Real-Time Strategy Game

A lightweight, mobile-first RTS game built with pure HTML5, vanilla JavaScript, and CSS3.

## Features

- 👷 **Workers** - Collect resources from deposits
- ⚔️ **Soldiers** - Attack enemy units and base
- 🎮 **Touch & Mouse Support** - Play on any device
- 🤖 **AI Opponent** - Challenging computer player
- 📱 **Mobile-First Design** - Optimized for phones and tablets
- 🎯 **Simple Controls** - Tap to select, tap to move
- 💎 **Resource Management** - Collect and spend wisely

## How to Play

1. **Collect Resources**: Create workers to gather resources from diamond deposits (💎)
2. **Build Army**: Use resources to create soldiers for combat
3. **Attack**: Select soldiers and move them to attack enemies
4. **Win**: Destroy the enemy base (🏰) while protecting yours (🏠)

### Controls

- **Tap/Click Unit** - Select unit
- **Tap/Click Map** - Move selected units to location
- **Tap Resource** - Send worker to collect automatically
- **Create Worker** - Costs 50 resources
- **Create Soldier** - Costs 75 resources

## Getting Started

Simply open `index.html` in a web browser, or serve via HTTP:

```bash
python3 -m http.server 8080
```

Then navigate to `http://localhost:8080`

## Tech Stack

- Pure HTML5
- Vanilla JavaScript (ES6+)
- CSS3 with mobile-first responsive design
- No frameworks or dependencies
- PWA-ready with manifest.json

## Browser Support

Works on all modern browsers with HTML5 Canvas support:
- Chrome/Edge (Desktop & Mobile)
- Firefox (Desktop & Mobile)
- Safari (Desktop & iOS)
